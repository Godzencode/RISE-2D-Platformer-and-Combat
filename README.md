# RISE: 2D Platformer and Combat

A 2D platformer game with a combat system and three distinct enemies, built in **Unity 6** with C#.

## About

I made this project to gain hands-on experience with 2D game development in Unity 6.

I followed a Udemy course as a structured guide for the early stages of the game and as an easy source of 2D assets. Beyond that, I added my own features and personal twists throughout, so the finished game goes well beyond what the course covers.

I understand everything in this project and can rebuild any part of it myself.

## Enemies

- **Patrolling enemy:** walks a set route
- **Guard enemies (two types):** hold their position, and one is stronger than the other

## Features

- Player attack
- Enemy attack
- Double jump
- Platforms
- Death line underneath the water
- Lighting with flames, lamps, and torches
- Particle effects
- Sound

## Built With

- Unity 6
- C#
- 2D assets from the Udemy course
